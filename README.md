# Firebow datapack

## Установка
1. Скопируйте папку datapack в `world/datapacks` сервера Paper.
2. Выполните `/reload` или перезапустите сервер.

## Тест
- Выдать лук: `/function firebow:give`
- Крафт: 3 blaze_rod и 3 string по рецепту datapack.
- Стрельба: нужны magma_block в инвентаре (в creative не тратятся).
